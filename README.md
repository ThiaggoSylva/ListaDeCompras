# 🛒 Lista de Compras

Sistema de gerenciamento de listas de compras desenvolvido em C# utilizando conceitos de Programação Orientada a Objetos (POO), arquitetura em camadas e boas práticas de desenvolvimento.

---

## 📌 Sobre o Projeto

O **Lista de Compras** é uma aplicação de console que permite ao usuário gerenciar listas, produtos e categorias de forma organizada, simulando um sistema real de controle de compras.

O projeto foi desenvolvido com foco em aprendizado, aplicando conceitos fundamentais como:

- Encapsulamento
- Abstração
- Polimorfismo
- Separação de responsabilidades
- Reutilização de código

---

## 🚀 Funcionalidades

### 📋 Módulo de Listas
- Criar nova lista de compras
- Editar listas existentes
- Excluir listas
- Visualizar listas cadastradas

### 🛍️ Módulo de Produtos
- Cadastrar produtos
- Editar produtos
- Excluir produtos
- Listar todos os produtos
- Evitar cadastro duplicado

### 🗂️ Módulo de Categorias
- Criar categorias
- Editar categorias
- Excluir categorias
- Associar categorias aos produtos

### 🔗 Associação de Produtos às Listas
- Adicionar produtos a uma lista
- Remover produtos da lista
- Visualizar itens da lista
